# 2D Space Shooter

A browser-based 2D space shooter built with HTML5 Canvas. No external images required — all graphics are drawn with simple geometric shapes.

## Play

**Controls:** Arrow keys to move, Space to shoot. On mobile, use on-screen buttons or drag the ship; tap FIRE to shoot.

## Run Locally

```bash
npm start
```

Open http://localhost:3000

Or open `index.html` directly in your browser.

## Features

- Move left/right with arrow keys
- Shoot bullets with spacebar
- Destroy falling enemies for points
- 3 lives, score counter, game-over screen with restart
